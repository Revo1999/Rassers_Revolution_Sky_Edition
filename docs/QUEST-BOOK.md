# Early quest book and free manuals

The current book has six chapters and 116 quests: 35 in From Nothing, 29 in
The Create Revolution, 28 in MI Steam Age, thirteen in Steel and Coolant, six Tips and
five Handbook quests. Chapter 4 adds the water-cooled Steel Drill after coke; see
[STEEL-DRILL.md](STEEL-DRILL.md) for its mechanics, costs and repair requirements.

Chapter 1 is arranged into four labelled areas: Grove & Compost, Soil Into Stone,
Clay/Water/Fire and Your First Drill. Every quest has an explicit item icon.
Larger hexagons mark milestones, circles mark normal steps and diamonds identify
optional side lessons/tools. Section banners use FTB's native chapter image/text
fields rather than a replacement screen or custom quest-book texture.

Chapter 2 teaches a workshop before requiring renewable power. The main route is
wooden drill -> smelted iron -> andesite/alloy/casings -> shafts/cogs/gearbox ->
hand-powered workshop -> press/depot -> 42 sheets -> iron drill parts -> a working
iron drill -> copper/tin for MI steam. The water-wheel branch then leads through
an unattended power line and automatic hatch-to-chest output. That branch is the
recommended automation goal; it does not block a manually commissioned iron drill
from unlocking the first steam chapter. Optional gold/wrench quests remain separate.

## Gearing and the hand crank

The pinned Create 6.0.10 Hand Crank generates 32 RPM with capacity 8 SU/RPM:
256 SU total. The iron drill uses 8 SU/RPM and requires at least 32 RPM, so one
dedicated crank can run it directly. Disconnect other machine loads first.

Small cog driving large cog halves speed. This is useful for a press or wooden
drill at 16 RPM, but will make the iron drill report Too slow. Large cog driving
small cog doubles speed and downstream stress demand. A single crank cannot
power the iron drill at 64 RPM because it then demands 512 SU.

A regular water wheel generates 8 RPM. Two 2:1 large-to-small stages produce
32 RPM. The wheel line must also have enough stress capacity; gear ratios do
not create more capacity. The quests request two wheels and explain adding more
as the workshop grows. These values were checked against the installed Create
classes and Revo's tier definition, without launching a client.

The 42-sheet upgrade budget covers twelve supports, eighteen casings (eight used
inside the controller), eight plates across two cores and four plates across the
two ports. Two cores also need eight loose iron ingots and their wooden components.

## Free manuals cannot supply resources

Tips still grants the Revolution Book, MI Guidebook, AE2 Guide and FTB Quest Book
without unlock guards. Its rewards automatically generate the optional-item tag
`revolib:free_quest_manuals`. Future manuals added to that reward list join the
policy when the chapter generator runs.

`FreeManualRecipes` filters recipes on the server before recipe synchronization,
at server startup and after datapack reloads (with a login fallback). It removes recipes consuming
those manuals, checking both normal ingredients and serialized custom machine
inputs/tags. Output fields are excluded, so ordinary recipes that create a manual
from earned ingredients remain available. Normal books remain part of progression.
If a shared recycling recipe accepts a free manual through a tag, that recipe is
removed as well. The server logs the recipe IDs it removes.

The pinned JSON recipe audit found no direct reverse recipe for the four manuals;
the guard also covers consuming recipes supplied through tags or generated by mods.
This policy makes replacement manuals information items rather than free feedstock.
It does not change how their guide interfaces open.

## Editing and progress

Existing chapter, quest and task IDs are preserved. Four new Create quests were
appended, so earlier completion records keep their identifiers. Do not insert nodes
into the sequential-ID generator in the middle of an existing chapter. Append them
or allocate a dedicated stable ID instead. Chapter 1's furnace now follows the stone
hammer, and the timber support task follows the core, to keep the map routes clear.

`scripts/quest_presentation.py` owns icons, positions, shapes and banners. The two
chapter generators call it, so regeneration preserves the new presentation:

1. Run `python scripts/generate_first_chapter.py`.
2. Run `python scripts/generate_create_steam_progression.py`.
3. Run `python scripts/generate_steel_drill_content.py` for Chapter 4 and steel resources, then `python scripts/generate_metal_farms.py` for the farm side branches. Run `python scripts/refine_greenhouse_tree_content.py` last to retain the five-block farm layouts, water tanks, fitted converter and updated quest instructions.
4. Run `python scripts/render_quest_maps.py` for offline previews in
   `art/quests/refreshed`. The game uses its own item renderer; the previews are
   layout checks, not captured gameplay.
5. Build with `dev.cmd assemble collectMods :revolib:syncPackOverrides` and package
   with `python scripts/package_modpack.py`.

The desktop launcher copies canonical overrides on a fresh launch. Existing worlds
keep their quest completion data. In a running world, FTB's reload command can reload
the definitions, but a fresh dev launch also loads the updated RevoLib recipe guard.

Verification remains light: compilation, stable IDs, icon/resource references,
dependency graph, wire/node clearance and packaged content. No Minecraft client or
GameTests were launched for this update. In-game layout and progression pacing are
left for the owner to play-test.
