# Machine polish and MV AE2 progression

AE2's inscriber, energy acceptor and controller now consume MI **Electronic Circuits**,
the second circuit tier (MV). All three finished processor recipes consume one too.
The three MI assembler alternatives have the same circuit cost, preventing that bypass.
Energy acceptor block/cable conversions remain free conversions of an already gated item.
Certus, silicon, presses and quartz resource preparation stay available beforehand.
Overrides retain upstream recipe IDs; `scripts/update_mv_ae2_recipes.py` records the pinned inputs.

The Salt Crystal Starter's stable item ID is retained for existing saves. It is now
displayed as **Salt Crystal Geode**, with an editable, vanilla-density white quartz/calcite
model. Quartz + sand + compost + water bucket crafts it without needing salt, and returns
the bucket. Place it in the **Iron Greenhouse**: each ten-second harvest costs 1600 EU
(8 EU/t) and 250 mB water, keeps the geode, and produces one MI salt dust. The unpowered
greenhouse rejects this program. EMI and quest instructions reflect the powered route.

Kelp and salt programs render a contained volume of animated, biome-tinted Minecraft
water. Water faces tile at one texture per block without sampling neighboring atlas
sprites. Kelp sways around its base and grows with actual progress; salt crystals grow
from their geode bed. The water stays level. Bubbles accompany paid processing.

The electric geological drill now synchronizes actual activity and spins its cooling
fan only while mining. Power loss and full output stop it. Mechanical drills retain
their driven bits/gears and gain contact dust; the sluice gains wash spray; compost
gains settling particles; silkworms move while feeding. Existing tree, crop and contained
mob animations remain tied to their real machine state.

## Original audio coverage

Superseded by [Quiet machine audio](MACHINE-AUDIO.md): continuous hums/motors,
45 sounds, volume controls and directional furnace hatches. The following describes
the original short-phrase implementation.

Sixteen original short Vorbis phrases are generated by `scripts/build_machine_sounds.py`.
They use positional BLOCKS audio, subtitles, quiet levels, short fades and a cadence
limited per block entity. Work phrases last under a second, so they cannot leave a
detached infinite loop after a machine stops or unloads. Passive machinery gets latch
feedback on interaction; storage winding/charging has mechanical feedback.

| Machinery | Work sound |
| --- | --- |
| Wooden / iron and steel / electric drills | Wood chatter / metal grind / motor whir |
| Greenhouses and tree growers | Irrigation trickle |
| Both harvester tiers | Harvest mechanism |
| Composter / silkworm cultivator | Settling / leaf rustle |
| Pumped sluice | Water wash |
| All vacuum tiers | Suction during actual item pulls |
| Crucible / rain barrel | Bubbling / collection and mixing |
| All converter tiers | Hum during energy forwarding |
| Storage terminal and drives | Crank/charge and interaction latch |
| All furnace tiers | Fire roar, existing vent smoke/crackle |
| Trading colony | Trade rustle |

`docs/machine-audio-validation.json` records decoded file duration, sample rate and peak.

## Model audit

`scripts/audit_model_planes.py` checks positive-area same-facing coplanar overlaps in
every runtime model definition and native source, including rotated cubes and meshes.
Parent geometry is audited at its defining file. The final scan covers 283 runtime definitions and 105 current native sources, with zero overlaps in either set. Opposing contact faces and zero-area
edge joins are excluded. Current sources and archival variants are listed separately.

Confirmed joins were separated through Blockbench's native Cube API using 0.004 model
unit offsets on detail surfaces, preserving UVs, materials and piece counts. The helmet
hose elbow was trimmed to meet cleanly, and the temple plate separated from its pod.
The native sources and runtime files are both updated. The fix script is idempotent;
run the audit after regenerating older models, whose original builders predate these fixes.

See `model-plane-audit.json` for all model results and `model-plane-fixes.json` for the
corrections. Historical backups deliberately retain their original geometry. A static
plane audit does not prove every possible shader/view/animation combination; native
client captures and sampled mechanical clearance checks supplement it.
