# Electric and Digital Drill sources

All editable sources and native Java exports were authored/exported using Blockbench MCP. Electric body starts from the repaired steel master, with UV-preserving visible-face partitions around the five native MI upper-layer hatch cells. It uses the existing steel atlas and moving bit/gear. Digital base and configurable MI face models were authored in the live Blockbench MCP session.

Digital textures are colour variants of the installed Modern Industrialization 2.5.11 steel casing, item hatch side, item output and energy hatch side sprites. Preserve MI attribution and licence alongside the existing MI dependency. Base screen pixels are authored locally at the same 16px scale.

Current production-source mappings live in `../surface-repairs/manifest.json`. Thin single-face partitions intentionally remove covered faces; they are not closed replacement volumes. Runtime collection may adapt loader/render metadata only. See `native-validation.json`, `docs/all-machine-model-audit.json` and `docs/steel-drill-hatch-clearance.json`.
