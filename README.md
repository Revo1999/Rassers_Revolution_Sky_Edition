# Rassers Revolution: Sky Edition

Development scaffold for Minecraft 1.21.1 / NeoForge 21.1.265 / Java 21.
Seven separate mod projects: RevoLib, RevoIndustry, RevoExtraction,
RevoCultivation, RevoGenetics, RevoStorage and RevoAchievements. RevoExtraction contains the wooden and iron drills; see
[the drill guide](docs/WOODEN-DRILL.md) for assembly and its current art limitations.
Cultivation and Genetics provide the wooden Tree Grower, Greenhouse and Mob
Harvester. Cultivation also provides the single-block Composter and Silk Worm
Cultivator; see [SINGLE-BLOCK-CULTIVATION.md](docs/SINGLE-BLOCK-CULTIVATION.md). RevoAchievements adds permanent quest-granted titles/hats and an
independent wardrobe; see [REVO-ACHIEVEMENTS.md](docs/REVO-ACHIEVEMENTS.md).

Chapter 1 now provides a renewable route from leaves to the first drill, with a
Revolution Book, crook, hammers, rain barrel and clay crucible. New islands have
a Crafting Station and start with only the book. See [FIRST-CHAPTER.md](docs/FIRST-CHAPTER.md).
Chapters 2 and 3 add 57 quests through Create, a 32+ RPM Iron Drill and the first
MI steam workshop. See [CREATE-IRON-STEAM.md](docs/CREATE-IRON-STEAM.md).
The early quest maps have refreshed icons/layouts and both crank and water-power
routes; freely granted manuals cannot be consumed as recipe ingredients. See
[QUEST-BOOK.md](docs/QUEST-BOOK.md).

The pack also includes Building Wands, Create: New Age and Flux
Networks with the coordinated Industrial Power Grid texture/name overlay. See
[INDUSTRIAL-GRID.md](docs/INDUSTRIAL-GRID.md).

The three single-block Power Converter tiers link MI EU and Flux FE in both directions without storing power,
using shared RevoLib compatibility. See [POWER-CONVERSION.md](docs/POWER-CONVERSION.md).

## Start

Open this directory in VS Code and allow the Gradle import to finish.
Local Java is configured through .local/java-home.txt and .vscode/settings.json.
On another machine, install JDK 21 and run:

    powershell -ExecutionPolicy Bypass -File scripts/configure-java.ps1 -JdkPath "C:\path\to\jdk-21"

From a terminal in this directory:

    .\dev.cmd build collectMods
    .\dev.cmd :revolib:runClient
    .\dev.cmd :revolib:runServer

The client and server run all seven projects together. Built jars are collected
in build/mods. Files from pack/overrides are copied into the run directory on launch.
Minecraft development assets download on the first setup.
The dedicated server requires you to review and accept Mojang's EULA in
revolib/run/eula.txt before it will start. Setup does not accept it for you.

## Layout

- Each revo*/src/main/java: Java implementation.
- Each revo*/src/main/resources/assets/<modid>: exported Minecraft assets.
- art/blockbench: editable model sources; see docs/BLOCKBENCH.md.
- pack/overrides: pack configuration, menu film, KubeJS and resource packs.
- docs/design: original user-supplied planning references.

The Departure Mono font pack is in pack/overrides/resourcepacks/revo-departure-mono.
Font by Helena Zhang, licensed under SIL OFL 1.1; see docs/FONT.md for use and credits.

New worlds default to the custom Revo skyblock island. FancyMenu replaces only the
vanilla title-screen background with a centered, character-free 20-second
Complementary Reimagined film at normal animation speed. Widgets and branding
use the vanilla/NeoForge layout, with the supplied pack logo replacing Minecraft's
logo, no yellow splash and no Create main-menu config button. Departure Mono uses its faithful native eight-pixel
capitals, as selected by the owner; FancyMenu's authoring bar is enabled for editing.
See docs/SKYBLOCK-AND-MENU.md for configuration, starter supplies and rebuilding.
The importable .mrpack prototype is generated by scripts/package_modpack.py.

## Dependencies and next steps

NeoForge and the Gradle wrapper are pinned from the official NeoForge 1.21.1 MDK.
The build downloads their dependencies automatically; standalone Gradle is unnecessary.
The full third-party design roster is installed in revolib/run/mods, including
the optional backpacks and performance candidates: 84 external jars plus seven
Revo development modules. See docs/MODS.md for the inventory. Exact versions,
download URLs and SHA-512 checksums are recorded in pack/mods.lock.json.
Restore those exact artifacts with:

    powershell -ExecutionPolicy Bypass -File scripts/sync-mods.ps1

Use -Resolve only when deliberately updating the baseline. These are runtime test
mods; add their documented development API dependencies when implementing integrations.
Skyblock Builder, Default World Type, FancyMenu, Watermedia, Iris and Sodium are
also pinned and installed. Complementary Reimagined is downloaded from its separate
shader lock and selected in Iris. MI Tweaks provides the selected EU/FE transformer.
A starter cosmetic quest chapter is implemented. The full progression, technology
gates, balancing and energy/charging validation remain future work. FTB's official Maven and CurseForge CDN artifacts are pinned in
pack/mods.external.lock.json and included by sync-mods.ps1. CurseForge is already installed on this machine
and can host a separate integration-testing profile.

The project repository is [Revo1999/Rassers_Revolution_Sky_Edition](https://github.com/Revo1999/Rassers_Revolution_Sky_Edition).
For a fresh development checkout, authenticate Git through Git Credential Manager;
`scripts\github-login.cmd` provides device sign-in. Local caches, runtime worlds,
downloaded dependency jars and machine-specific settings are excluded from Git.

Sources: https://docs.neoforged.net/docs/1.21.1/gettingstarted/
and https://github.com/NeoForgeMDKs/MDK-1.21.1-ModDevGradle

Revo machine asset conventions and exact block-layer heights are recorded in

drill controller opens a diagnostics-only interface; its output hatch opens storage.
The controller uses a small black Revo R at the bottom-right; the hatch has no branding footer.

Interactive 3D EMI construction guides for the drill and future Revo multiblocks are documented in [REVO-MULTIBLOCK-GUIDES.md](docs/REVO-MULTIBLOCK-GUIDES.md).

Simply Light and Simply Graves are included. Simply Graves replaces Soul Gravestone in the active pack.

Machine UI, standard player inventories, automatic hatch output, orientation errors and Jade integration follow [MACHINE-INTERFACES.md](docs/MACHINE-INTERFACES.md).

Building options include five Macaw's mods (Fences and Walls, Doors, Windows, Roofs, Stairs), Create Deco and BetterBlockZ.

The water-cooled Steel Drill is the third extraction tier, with real vanilla-water tank rendering, dry-running damage, repair kits and ten Chapter 4 quests. See [STEEL-DRILL.md](docs/STEEL-DRILL.md).

Steel Tree Grower / Mob Harvester upgrades and an Iron Electric Greenhouse with glass, powered grow lights and an integrated converter are documented in [METAL-FARMS.md](docs/METAL-FARMS.md).

### RevoIndustry furnace multiblocks

Ten Iron Furnaces tiers now have native MI-backed 3 x 3 x 3 multiblocks, permanently parallel smelting, three item-hatch grades, nine solid/liquid/gas fuel inputs and an adapting roof vent. Factory Augments are disabled. See [furnace recipes, structure and validation](docs/REVO-FURNACES.md).
